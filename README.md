# Oshi Pocket legal site

Public, static Privacy Policy and Support pages for App Store Connect and Google Play.

- Site: `https://yamasaku.github.io/oshi-pocket/`
- Privacy Policy: `https://yamasaku.github.io/oshi-pocket/privacy.html`
- Support: `https://yamasaku.github.io/oshi-pocket/support.html`

The site supports Japanese, Traditional Chinese (Hong Kong) and English. It contains no analytics, advertising, tracking cookies, external fonts or third-party scripts. The only browser storage is the selected language code.
